# JBM Holding Master

App em `jbm-master-app/` — deploy no Vercel como projeto **jbm-master**.

## Vercel — Root Directory

No projeto https://jbm-master.vercel.app configure:

**Settings → General → Root Directory:** `jbm-master-app`

## Variável de ambiente

`VITE_JBM_PASSWORD` = sua senha de login

## Cashflow

Dados de https://bebidas-control.vercel.app/api/cashflow-export (sync automático 15 min).
